# THRUST ROADSTER — TENMA EDITION

断崖から跳び、**道のない都市**を壁で駆け、**嵐**を突き抜けて**宇宙**へ。
そして、出発した台地へ**帰ってくる**。

左右・推力・緊急ブーストの **3つの操作** で遊べる、約9分の物語型 3D フライト・アドベンチャーです。
「スラスト・ロードスター」シリーズ（PULSE/ULTRA → CLIFF → SKYDROP）の最終形として、
`Thrust_Roadster_TENMA_最終要件定義_詳細仕様書` とアセットキット v1 に沿って作りました。

設計の考え方・仕様との対応表は [JOURNEY.md](JOURNEY.md) にまとめています。

## 遊び方
`index.html` をブラウザで開くだけ（ビルド不要、Three.js 同梱、外部通信はWebフォントのみ）。
キットのPNGテクスチャ・WAV効果音も使うには、簡単なサーバー経由で開いてください：
`npx http-server .` または `python3 -m http.server`（file:// で開いた場合は手続き生成の代替素材で動きます）。

| 操作 | キーボード | スマホ | ゲームパッド |
|---|---|---|---|
| 左右に操舵 | ← → / A D | 左下の ◀ ▶ | 左スティック／十字 |
| 推力（押している間だけ上昇・燃料を使う） | Space / ↑ / W | 右下「推力」長押し | A |
| 緊急ブースト（ENERGY満タン時のみ） | Shift | 推力の上の「BOOST」 | RT / X |
| ポーズ | Esc / P | 右上 II | Start |

## 5つの章
| 章 | 舞台 | 新しい体験 | クリア条件 |
|---|---|---|---|
| S1 GRAVITY CLIFF 重力の断崖 | 夕焼けの台地と峡谷 | 走る→浮く→谷越え、**断崖からの大ジャンプ**（地平線が開く） | 峡谷出口のゲート |
| S2 ROADLESS CITY 道のない都市 | 夜のネオン摩天楼 | **壁面走行**、空中車両との**ニアミス**、発着パッドで給油 | 都市頂上の気流ゲート |
| S3 SKY BREAKER 天空突破 | 雷雲と雲海 | **竜巻で上昇**、**落雷**（約1秒前に予告）、**重力反転ゲート**、雲が割れる光の柱 | 成層圏の出口 |
| S4 COSMIC ODYSSEY 宇宙の旅 | 地球を見下ろす宇宙 | **静寂の演出**、低重力と慣性、**光のビーコン**、帰還航路の選択 | 急降下／緩降下ゲート |
| S5 EARTH RETURN 地球帰還 | 大気圏→雲→夜明けの台地 | **熱・角度・減速**の再突入、出発した台地への着陸 | 安全な着地点へ帰還 |

章と章は暗転せず、空・霧・光・雲・音楽がそのままつながります。

## 主な仕組み
- **燃料**：推力で減り、地面・発着パッド・燃料セル・気流の中・壁面走行で回復。
- **ENERGY / 緊急ブースト**：ニアミス・連続リング・壁面走行・竜巻・パーフェクト着地、そして**安全なオレンジの光球**でもたまる。満タン時のみ使用可（誤操作防止）。2.8秒の加速＋上昇＋無敵。
- **救済**：墜落が決まる直前に 0.7〜1.2 秒のスロー＋自動回避（章ごとに かんたん3／ふつう2／むずかしい1回）。救済は通常クリア扱いで、記録には別記。
- **連続失敗**：3回でヒント、5回で操作アシスト強化を提案（自動クリアはしない）。
- **着地評価**：斜面に対する垂直速度と機体角度。着地点ガイド（緑／黄／赤）。
- **スコア**：章ごとに「到達・リング・技術・探索・安全・速さ」で正規化（最大10,000）。危険なニアミスだけが最適解にならない配分。
- **記録**：ローカル保存（章別ベスト、ランキング上位5件、解放状況）。タイトルの「記録」から消去可能。初回ストーリークリアで**章別タイムアタック**が解放。

## 設定（アクセシビリティ）
BGM・効果音の音量／個別オン・オフ、字幕、画面の揺れを抑える、点滅・フラッシュを抑える、救済のスロー演出、演出を短くする、振動、着地ガイド、操作アシスト（標準／強め／最大）、画質（自動／高／中／低）。
重要な合図はすべて文字・アイコンでも表示します（音だけに頼らない）。`prefers-reduced-motion` を尊重します。

